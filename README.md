# Office Buddy

Office Buddy la Office Add-in cho Microsoft Word (yo office + React + TypeScript). Ung dung la tro ly AI cho he thong eOffice, ho tro tra loi quy dinh noi bo va soan thao van ban hanh chinh tieng Viet trong task pane.

## Cach chay (client)

```bash
cd client
npm install
npm start
```

Sau khi chay, mo Word va bat add-in de xem giao dien task pane.
